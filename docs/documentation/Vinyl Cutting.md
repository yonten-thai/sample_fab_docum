# 1. What is a Vinyl Cutter?
It is a machine that uses a tiny blade to cut out designs from adhesive sheets, controlled by a computer.

# 2. Key Components
Cutting Blades: The machine uses small blades with different angles (30°, 45°, or 60°) depending on how thick the material is and how detailed the cuts need to be.
Pinch Rollers: Adjustable wheels that hold the vinyl flat and feed it evenly through the machine.

# 3. Setting Up the Machine
Making the Rollers Loose: To do that you need to lift the top lever and load the material.
Vinyl Sheet/Roll Positioning: Then, you slid the vinyl sheet/roll in, make sure to lay it flat and aligned with the guide marks to prevent feeding crooked.
Locking the Rollers: After step 2, you need to shift the white pinch rollers into position over the marked areas and flip the top lever back down to secure the sheet/roll.
Selection of Sheet Type: On the machine display, you need to select from the material setting(Given: Piece, Edge or Roll) so that the machine is able to read the size of the sheet of your choice.

# 4. Software Setup & Cutting Workflow
You need to use Roland CutStudio for the design preparation and transferring it to the cutter.

# Preparing the File in CutStudio

Get Sheet Measurements: Go to  File > Cutting Setup > Change and click Get from Machine.

Import & Vectorize: Next you import your design into CutStudio, then right click the image to Image Outline as one of the option, so you can generate the cut paths around your design.


Extract Contour Lines: After step 2, you need to extract the outer contour lines to so that the blade can follow the defined edges.


Send to Cutter: Lastly, you need to Ctrl + P to send over the file to the vinyl cutter.


# 5. Finishing Touches: Weeding & Transferring

Weeding

After the cutting is done, you pull the vinyl sheet out and start peeling off all the background areas and extra pieces, suing a small pick.

# Transferring the Design

For the final step, you need to tape a sticky transfer tape on it to weed the design out. The tape holds all the separate parts of the graphic in their exact positions so you can lift the entire decal off the backing paper and press it neatly onto your final surface.
